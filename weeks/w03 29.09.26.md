```javascript
let x = 20;

function setup() {
  createCanvas(600, 400);
}

function draw() {
  background(240);

  circle(x, 200, 30);

  x = x + 1;
}
```
Every time `draw()` runs, `x` increases by 1. This is why the circle moves to the right.



```javascript
let size = 20;

function setup() {
  createCanvas(600, 400);
}

function draw() {
  background(240);

  circle(width / 2, height / 2, size);

  size = size + 1;
}
```
`size` stores the current size. Every time `draw()` runs, the value increases by 1. This is why the circle grows.


3. Cycle:
Now the circle does not grow forever. It gets bigger, then smaller, and then bigger again. By changing `0.05`, you can control the **speed** of the cycle. By changing `50`, you can control the **strength/range** of the size change.
```javascript
function setup() {
  createCanvas(600, 400);
}

function draw() {
  background(240);

  let size = 100 + sin(frameCount * 0.05) * 50;

  circle(width / 2, height / 2, size);
}
```

4. Real World time
`hour()`, `minute()` and `second()` allow me to use real-world time as input for my visual system.

https://editor.p5js.org/Phariya/sketches/T1ZqfIAlR

```javascript
function setup() {
  createCanvas(600, 400);
}

function draw() {
  background(240);

  let h = hour();
  let m = minute();
  let s = second();

  textSize(30);
  text(h + ":" + m + ":" + s, 50, 100);
}
```

5. Timepiece concept: 

My timepiece represents time through particles inside circular vessels.

Each circle represents one hour. During the current hour, the circle gradually fills with particles as the minutes pass. When one hour is complete, the circle is full and a new circle begins to fill.

The particles move continuously inside the circles. This movement represents the continuous passage of time.

The colour of the particles shows whether it is day or night. After twelve hours, the system resets and the cycle begins again.

The system translates time into visual behaviour:

- **Hours → number of filled circles**
    
- **Minutes → number of particles**
    
- **Seconds → movement of the particles**
    
- **Day / night → colour of the particles**
    
- **12 hours → reset and begin a new cycle**

https://editor.p5js.org/Phariya/sketches/4wkG9PhIh

```javascript
let centerX;
let centerY;

function setup() {
  createCanvas(600, 600);
  angleMode(DEGREES);

  centerX = width / 2;
  centerY = height / 2;
}

function draw() {
  background(240);

  noFill();
  stroke(0);

  for (let i = 0; i < 12; i++) {
    let angle = i * 30;

    let x = centerX + cos(angle) * 200;
    let y = centerY + sin(angle) * 200;

    circle(x, y, 70);
  }
}
```
