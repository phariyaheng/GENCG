# Code Cadavre Exquis

## My Starting Point

I start with a simple line that goes from the center of the canvas to the mouse. A point is also drawn at the current mouse position.

```
function setup() {
  createCanvas(600, 600);
  background(240);
}

function draw() {
  // Line
  strokeWeight(1);
  line(width / 2, height / 2, mouseX, mouseY);

  // Points
  strokeWeight(6);
  point(mouseX, mouseY);
}
```

## What Happens?
- The line always starts in the center.
- The end of the line follows the mouse.
- Points appear at the mouse position.
- Previous lines and points stay visible.
- Moving the mouse slowly creates a pattern.

## Idea

The starting point is intentionally simple and open. The next person can read the code and decide how they want to continue or change it.

# Next Step

My partner changed the movement and used `noise()` to create a smoother and more organic path.
## What I Changed
- I changed the background to black.
- I made the lines light blue.
- I made the points white-blue and slightly transparent.
## Code

```javascript
function setup() {
  createCanvas(600, 600);
  background(0);
}

function draw() {
  // Random Position
  let x = noise(frameCount * 0.01) * width;
  let y = noise(frameCount * 0.01 + 1000) * height;

  // Light blue lines
  stroke(100, 180, 255, 60);
  strokeWeight(1);
  line(width / 2, height / 2, x, y);

  // White-blue points
  stroke(220, 245, 255, 100);
  strokeWeight(6);
  point(x, y);
}
```

## What Happens

The lines move smoothly across the black background and create a light blue pattern. The white-blue points follow the movement and create a slightly transparent, glassy effect.
